# SnapNest

SnapNest is an image-search website where users will be able to search for images and view them in a responsive grid.

I chose a dark teal and orange colour theme to make the website look different from the PixelPulse reference and give it a modern appearance.

I added category chips for common searches so users can quickly choose topics such as Nature, Animals, Cities, and Space.

I also added an empty-state message and a result-count placeholder so users understand what will happen when they search.
